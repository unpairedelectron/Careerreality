# Salary Reality — privacy

The entered target CTC stays in React page state. Role, city, and experience are sent to the first-party API to retrieve an aggregate benchmark; manual analytics events contain the route and tool name, not the target amount.

Do not serialize planning values into the URL or sign-in redirect. The page offers no user save action in this flow. API access logs and retention are governed by the backend and were not independently audited for this document.
