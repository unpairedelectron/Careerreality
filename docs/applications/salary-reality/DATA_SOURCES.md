# Salary Reality — data sources

- Benchmark records come from the first-party public salary-benchmark API.
- A usable record carries provenance fields for source type, publication/retrieval/review dates, methodology name/version, metric, transformation, inputs, and limitations.
- Role, city, and experience are sent to request an aggregate record. The target CTC is kept in browser state and is not included in analytics.
- The current live dataset, sample size, coverage, and representativeness were not re-audited for this report. No source is named here unless it is present on the individual record.
