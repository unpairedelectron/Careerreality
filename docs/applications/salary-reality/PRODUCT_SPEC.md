# Salary Reality — product spec

## User need
Let a candidate compare a target annual CTC with a role-, city-, and experience-specific market band when eligible, current evidence exists.

## Inputs and output
Role, city, and experience select a benchmark request. Target CTC remains a local planning input. The page may show P25, median, P75, and a plain-language comparison only for eligible records.

## Non-goals
The result is not a salary guarantee, percentile promise, take-home estimate, or instruction to accept or reject an offer. Missing or stale evidence must produce an unavailable state.
