# Career Reality Index — before and after

**Before:** Conditional branches made strong claims about employer risk, market leverage, AI exposure, and whether a move was appropriate based only on four self-ratings; an analytics event also recorded a derived diagnosis type.

**After:** The page displays a fixed self-reflection prompt and all four selected responses, with a visible statement that it is not an employer or career verdict. Derived diagnosis analytics were removed; explicit workspace saving remains a separate user action.
