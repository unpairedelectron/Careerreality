# Career Reality Index — product spec

## User need
Help a person name their current feelings about pay, company confidence, ability to move, and AI readiness, then consider what evidence they would want to check.

## Inputs and output
The user selects one self-reported response for each of four areas. The page repeats those answers and displays a fixed reflection prompt; it does not rank or combine the answers.

## Non-goals
It is not an index, objective diagnosis, employer assessment, salary benchmark, job-security forecast, or stay/leave recommendation.
