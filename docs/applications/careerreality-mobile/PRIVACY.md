# CareerReality Mobile — privacy

Profile and saved decision data can be synchronized to first-party APIs for signed-in features. Users must be able to distinguish local draft state from account-saved state and should review what a saved item contains before confirming.

The app can handle sensitive career context. Do not put compensation, profile answers, or saved summaries into URLs or analytics. Retention, export, deletion, device storage, and provider-specific data flows require verification against the live account/API implementation before making broad claims.
