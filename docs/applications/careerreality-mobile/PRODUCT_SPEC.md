# CareerReality Mobile — product spec

## User need
Give signed-in users a mobile workspace for a personalized market brief, next-step planning, job discovery, watchlists, and saved career context.

## Inputs and output
The app uses an authenticated profile and first-party API evidence to populate mobile screens. It should carry source/freshness state into briefs and plans and allow users to review or update saved work.

## Non-goals
The mobile app does not guarantee job availability, employment outcomes, company safety, or uninterrupted provider access. A native release is not considered verified until real-device sign-in and signed-in flows pass.
