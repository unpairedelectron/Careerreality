# CareerReality Mobile — known limitations

- Native authentication has automated contract coverage but no release-device smoke-test result.
- Live data/provider access can fail; job and company evidence may be incomplete or stale.
- A personalized brief is only as reliable as profile completeness, provenance, and current source coverage.
- Screen-reader, dynamic text, keyboard, device performance, and offline behavior need real-device review.
- The public landing page stays noindex until mobile release readiness is confirmed.
