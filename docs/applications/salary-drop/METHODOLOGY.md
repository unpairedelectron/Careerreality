# Salary Drop planner — methodology

The model applies the same fixed share, `1 - variable-pay percentage`, to both annual CTC amounts. It divides the difference in assumed fixed cash by 12 for a monthly amount. The buffer is the absolute value of a negative monthly difference times the selected number of months; the cost percentage divides the monthly difference by the entered cost baseline.

This arithmetic assumes the same variable-pay share for both packages and does not estimate actual payout, taxes, employer contributions, benefits, expenses, or inflation.
