# Salary Drop planner — known limitations

- Both offers are assumed to have the same variable-pay percentage.
- CTC is treated as a package input; employer-paid items, taxes, benefits, and payout probability are not normalized.
- The monthly cost baseline is user-entered and may not include all household obligations.
- Buffer arithmetic is a scenario amount, not proof of financial safety.
- Automated model tests exist; full route and assistive-technology verification remain.
