# Salary Drop planner — product spec

## User need
Model how a lower or higher offer changes assumed gross fixed cash and compare that difference with a user-selected expense baseline and buffer.

## Inputs and output
The user enters current/new annual CTC, a shared variable-pay percentage, monthly cost baseline, and buffer months. The result shows assumed fixed cash, monthly/annual difference, buffer amount, and cost-relative difference.

## Non-goals
It is not take-home pay, a tax calculation, a household budget, or a recommendation to accept a lower-paying role.
