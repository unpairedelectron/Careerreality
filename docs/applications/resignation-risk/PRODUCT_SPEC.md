# Resignation Risk — product spec

## User need
Help a person list concrete facts to verify before a possible resignation without pretending to calculate whether leaving is safe.

## Inputs and output
The checklist accepts a 30/60/90-day notice selection, offer status, user-entered cash runway from 0–60 months, and whether a repayment clause needs review. It returns the selected facts and conditional next checks.

## Non-goals
It does not calculate risk, prescribe a universal runway threshold, interpret a contract, or decide whether the user should resign.
