# CTC / in-hand calculator — product spec

## User need
Help a candidate understand how an annual offer may translate into monthly cash without treating headline CTC as salary.

## Inputs and output
The form accepts offer structure, fixed and target variable pay, employer-paid items, PF assumptions, a state/professional-tax input, and a selected tax regime. It returns an estimate with the entered assumptions visible.

## Non-goals
This is not a payslip, tax filing, tax opinion, guaranteed variable-pay forecast, or offer recommendation. A qualified tax review is still a release blocker.
