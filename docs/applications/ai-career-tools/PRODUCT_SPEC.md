# AI / Career AI prompts — product spec

## User need
Give a worker structured questions for examining which tasks are changing and what evidence of judgment or accountability they can show.

## Inputs and output
The current page presents role/task prompts and practical questions. It does not accept a resume, run a model, or return a role-level exposure score.

## Non-goals
It is not an AI displacement forecast, employment-probability model, skill guarantee, or claim that any particular job will disappear.
