# AI / Career AI prompts — technical spec

The `/ai` route renders static prompt content and local page interactions. No model provider or career-profile API is required for the current experience. Legacy routes must resolve to the reviewed prompt page or a genuine not-found state; they must not preserve unsupported numeric claims.

Search copy describes the tool as task-level prompts, not role-impact scoring. The route must keep its explanatory content in generated static HTML.
