# Company Intelligence — data sources

- Search and detail records are requested from first-party public company-signal endpoints.
- Individual records may include a source URL, source label, confidence, method version, retrieval/review dates, transformations, inputs, and limitations.
- The app does not have a reviewed score dataset for stability or hiring momentum; those outputs are suppressed.
- The current live record set and company-by-company source freshness were not re-audited in this staging assessment.
