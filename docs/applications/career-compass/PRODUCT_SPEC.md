# Career Compass — product spec

## User need
Help a person compare an offer, a possible move, and staying without collapsing different evidence into one score.

## Inputs and output
The page uses role, city, current and offered annual CTC, notice-period input, and separate salary/company/layoff evidence states. It presents three distinct readouts and exact annual CTC arithmetic only when both CTC values are valid.

## Non-goals
Compass does not predict job security, determine whether an offer is good, estimate after-tax pay, or recommend accept/reject/resign/stay.
