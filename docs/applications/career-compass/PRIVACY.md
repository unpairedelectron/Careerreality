# Career Compass — privacy

CTC, role, city, and notice inputs are held in the page. Salary/company/layoff requests retrieve their own evidence; the CTC values are not sent with those queries. Manual analytics events are route/tool-level only.

Saving is a separate, user-initiated action that sends a decision note to the authenticated workspace; the saved note can contain user-entered career context. No such save occurs merely by calculating. Do not preserve arbitrary query parameters in sign-in redirects.
