# Layoff Radar — methodology

Only signals accepted by `usableLayoffSignals` are rendered. The page calculates a descriptive count and high-confidence share from the returned records; the share describes evidence labels in that response, not the likelihood of future layoffs.

The current taxonomy does not consistently separate official announcements, independently reported events, rumours, restructuring, and hiring slowdowns. This is a hard blocker: do not upgrade a record's source wording into a confirmed event or publish a forecast.
