# Layoff Radar — privacy

Search text and selected type are sent to the first-party API. A submitted report includes the company name, description, and confidence selection; the server redacts email, URL, and phone-like text before storage. The intake form does not request a name or contact field.

The UI permits anonymous submission and says reports stay private during moderation. Do not include names or confidential employer material in a report. Data retention, abuse-monitoring metadata, deletion process, and the complete publication gate still need owner/security review.
