# Layoff Radar — product spec

## User need
Inspect dated company changes and the evidence attached to each signal; submit a report for private review when a relevant signal is missing.

## Inputs and output
Users can search/filter available layoff, hiring-freeze, hiring, and restructuring labels. Results show company, signal text, observed date, confidence label, source label, citation, and provenance details. A report form accepts a company, description, and submitter-selected confidence.

## Non-goals
The radar is not a layoff forecast, employer safety score, or instruction to resign. A source label is not proof that an event was officially announced.
