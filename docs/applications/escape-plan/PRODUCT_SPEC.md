# Escape Plan — product spec

## User need
Turn a broad career concern into a bounded list of reversible actions and a time budget.

## Inputs and output
The user chooses a goal (better role, more money, healthier team, or different career), a 4/8/12-week window, and hours per week from 1–40. The page presents five goal-specific prompts and an exact total-hours calculation.

## Non-goals
It does not estimate job-search success, readiness to resign, or the time a career change will actually take.
