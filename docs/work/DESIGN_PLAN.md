# Design plan

## Visual system

- **Ink** `#1E2B30` for primary text and high-contrast tool results.
- **Paper** `#F3F2EC` for the reading canvas, chosen for long-form legibility rather than as a generic cream-and-serif theme.
- **Deep teal** `#176F66` for actions and verified-result emphasis.
- **Signal blue** `#25AEE4` for the CareerReality mark and secondary interactive states.
- **Rule grey** `#D5DAD5` for borders that separate information without card shadows.
- **Caution ochre** `#A86B16` for explicit assumptions and review warnings.

## Type and layout

Use the existing editorial display face for page titles, Manrope for body copy and controls, and a monospaced face only for numeric values and dates. Keep explanatory text at 16 px or larger, with compact labels reserved for form metadata. Use a two-column offer-input/result layout on wide screens; stack the result immediately after the inputs on narrow screens. Use borders and tables to show calculation structure, not a repeated grid of rounded cards.

## Principles

Make the active calculator and its assumptions the first useful action. Keep the homepage focused on the offer question and avoid unsupported company or market claims. Navigation should expose only live tools and working trust pages. Motion should indicate a state change and respect reduced-motion preferences; do not animate every section. Use arrows only when an external destination or an actual transition needs clarification.

## Generated-default review

The existing paper background and serif display face are retained because the product is a reading-and-calculation desk; they are paired with teal and blue rather than terracotta. The plan rejects uniform soft-shadow cards, all-caps labels above every heading, fragment-style section names, arrow-suffixed links, and decorative fade/slide motion. Keep the current brand mark; remove navigation and cards for quarantined material.
