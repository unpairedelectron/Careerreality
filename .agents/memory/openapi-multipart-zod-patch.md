---
name: OpenAPI multipart Zod patch
description: Multipart request schemas generated by Orval need a post-generation rename to avoid duplicate exports.
---

When adding a multipart endpoint to the shared OpenAPI spec, Orval emits the request body schema in both the generated API module and generated types. Rename the body schema export in the post-generation patch, and normalize generated file endings.

**Why:** Without the patch, the shared Zod package fails its barrel export typecheck; generated trailing blank lines also fail the repository diff check.

**How to apply:** Extend `patch-generated.mjs` for each new multipart body schema, then run the API spec codegen before checking libraries, API, and mobile.
