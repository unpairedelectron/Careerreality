---
name: Layoff planner privacy
description: Privacy boundary for role and runway inputs on layoff event pages.
---

Role family, report-match confidence, accessible cash, expected one-time pay, and essential monthly spend stay in page memory only. Do not persist them, put them in a URL, or send them to an API or analytics.

**Why:** Layoff planning combines sensitive employment context with personal financial estimates; the personalized plan should not create a stored profile.

**How to apply:** Preserve this boundary when extending the event-detail planner or linking it to other career tools.
